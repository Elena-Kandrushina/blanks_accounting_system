## Установка:

1. Клонируйте репозиторий:
```
git@github.com:Elena-Kandrushina/blanks_accounting_system.git

```

2. Установите зависимости:

```
poetry install
```
3. Запуск Redis:

```
redis-server
redis-cli

```

4. Запуск проекта после запуска Redis:

```
python manage.py runserver
```
