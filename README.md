# Проект "Система учета заготовок (blanks_accounting_system)"

## Описание: 
Веб-приложение для автоматизации учета заготовок на складе, их движения на производственные участки,
контроля качества и сборки готовых изделий с автоматическим списанием материалов.

## Функциональность

### Номенклатура
- Учет заготовок (артикул, наименование, категория, единица измерения)
- Учет изделий и норм расхода (связь изделие-заготовка)
- Автоматическая проверка уникальности артикулов

### Складской учет
- Управление складами
- Остатки заготовок на складах с контролем минимального запаса
- Движения заготовок (поступление, перемещение, списание)
- Автоматическая генерация номеров документов (MOV-YYYYMMDD-XXXX)

### Производство
- Производственные участки (привязка к складам)
- Заявки на выдачу заготовок (создание, обработка, отмена)
- Статусы заявок: Новая, В обработке, Выполнена, Отменена
- Отчеты о сборке с автоматическим списанием заготовок по нормам
- Остатки заготовок на участках

### Контроль качества (ОТК)
- Справочник видов брака
- Акты о браке с подтверждением и автоматическим списанием
- Двойной контроль: создание и подтверждение актов

---

## Роли пользователей

| Роль | Описание | Доступные функции |
|------|----------|-------------------|
| **Администратор** | Полный доступ | Управление пользователями, все функции системы |
| **Технолог** | Работа с номенклатурой | Заготовки, изделия, нормы расхода |
| **Кладовщик** | Складской учет | Остатки, движения, обработка заявок |
| **Мастер участка** | Управление производством | Создание заявок, отчеты о сборке |
| **Ст. контролер ОТК** | Контроль качества | Акты о браке, справочники |

## Установка:

1. Клонируйте репозиторий:
```
git@github.com:Elena-Kandrushina/blanks_accounting_system.git

```

2. Установка и запуск через Docker
 - Создайте файл .env из примера .env.sample
 - Запустите контейнеры
```
docker-compose up -d

```
- Выполните миграции
```
docker-compose exec web python manage.py migrate

```
 - Создайте группы пользователей
```
docker-compose exec web python manage.py create_user_groups

```
 - Создайте суперпользователя
```
docker-compose exec web python manage.py createsuperuser

```
- Для удобства использования заполните тестовыми данными 
```
docker-compose exec web python manage.py fill_test_data

```
- Соберите статические файлы 
```
docker-compose exec web python manage.py collectstatic --noinput

```
- Откройте в браузере 
```
http://localhost:8000

```
- Остановка контейнеров 
```
docker-compose down

```
